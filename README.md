# ReNook
ReNook is a simple and responsive book sharing website where users can borrow and lend books online.
The project is built using HTML, CSS, JavaScript, and Bootstrap.

Features:
1. Borrow books
2. Lend books
3. Search books availability
4. Shared reusable header and footer
5. Responsive UI
6. Bootstrap styled components

Technologies Used:
1. HTML
2. CSS
3. JavaScript
4. Bootstrap

How It Works: 
- Users can search for books on the Borrow page.
- JavaScript checks whether the entered book exists in the stored array.
- Users can add books from the Lend page.
- Shared layouts are reused across pages using JavaScript.
